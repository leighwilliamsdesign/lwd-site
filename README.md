# lwd-site

Leigh Williams Design website. Plain HTML, published by Vercel from the main branch.

- `index.html`: holding page
- `api/contact.js`: emails the contact form through Resend
- `images/`, `fonts/`: logo and web fonts

Private settings live in Vercel, not in this repository: `RESEND_API_KEY`, `CONTACT_TO`, `CONTACT_FROM`.
